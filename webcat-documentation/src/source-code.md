WEBCAT aims to be fully transparent and reproducible. As such, all its components are publicly developed and available under open source licenses.

### Repositories
WEBCAT components are distributed in several different repositories, under the [freedomofpress](https://github.com/freedomofpress) GitHub organization.

 - [webcat-spec](https://github.com/freedomofpress/webcat-spec) - Text-based protocol and format specifications
 - [webcat](https://github.com/freedomofpress/webcat) - [Browser extension](concepts.md#browser-extension)
 - [webcat-cli](https://github.com/freedomofpress/webcat-cli) - Command line utilities for [web app developers](concepts.md#web-app-developers) and [site operators](concepts.md#site-operators)
 - [webcat-infra-chain](https://github.com/freedomofpress/webcat-infra-chain) - Consensus-based enrollment distributed system
 - [webcat-docs](https://github.com/freedomofpress/webcat-docs) - This documentation website

### Demo
The demo websites are also open source:
 - [test.demo.webcat.tech](https://github.com/freedomofpress/webcat-demo-test) - Example web app
 - [element.demo.webcat.tech](https://github.com/freedomofpress/webcat-demo-element) - Element Matrix client
 - [enrollment-error.demo.webcat.tech](https://github.com/freedomofpress/webcat-demo-enrollment-error) - Example page showing an enrollment mismatch
 - [manifest-error.demo.webcat.tech](https://github.com/freedomofpress/webcat-demo-manifest-error) - Example page showing a [manifest](concepts.md#manifest) validation error
 - [integrity-error.demo.webcat.tech](https://github.com/freedomofpress/webcat-demo-integrity-error) - Example website displaying integrity errors for various resources
