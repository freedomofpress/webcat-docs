# For web app developers
This section contains information useful for [web app developers](../concepts.md#web-app-developers) who want to ensure compatibility of their web app with WEBCAT.

> We are working to make this process more clear, accessible and straightforward. We welcome feedback on the [documentation, in its repo](https://github.com/freedomofpress/webcat-docs). If you are a web app developer or a [site operator](../concepts.md#site-operators) and have issues following this process, feel free to file an issue in the [extension GitHub repository](https://github.com/freedomofpress/webcat).

You may find it useful to first understand some concepts outlined in the [Glossary](../concepts.md#glossary) section.

Next, read WEBCAT's [Requirements](./requirements.md).
